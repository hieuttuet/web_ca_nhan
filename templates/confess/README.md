# 💘 Danh Mục 1: Tỏ Tình (`confess`)

Thư mục chứa các bộ Template thuộc sự kiện **Tỏ Tình** (`category: 'confess'`).

## Cấu trúc thêm bộ Template mới:
Mỗi bộ template đặt trong 1 thư mục con riêng:
- `templates/confess/tpl-01-ten-mau/index.html`
- `templates/confess/tpl-02-ten-mau/index.html`
...
Sau đó khai báo thông tin & giá bán vào mảng `CONFESS_TEMPLATES` trong `/templates-catalog.js`.
